# Style Bible — Soul Split

Канон визуала для Gemini и всех ассетов. Менять только осознанно (и тогда обновить skill).

**Статус стиля портретов врагов/юнитов:** LOCKED  
**Эталон:** [`approved/enemy_portrait_example.jpg`](approved/enemy_portrait_example.jpg)

## Сеттинг мира

Микс **средневекового фэнтези** и **стимпанка**: магия и технологии сосуществуют, **магия преобладает**.  
В ассетах: доспехи, плащи, руны, кристаллы — рядом с шестернями, латунью, клапанами, линзами; tech вторичен, не sci-fi.

## Общий визуальный канон

| Параметр | Решение |
|----------|---------|
| Техника | **Hard toon / cel-shade** — чёткие плоскости света и тени |
| Контур | Чёткий **тёмный** внутренний контур (тонкий/средний, не жирный) + **тонкий** белый sticker-outline вокруг силуэта (~2–3px относительно панели, ровный, близко к краю). **Не** толстая белая «обводка-маркер» |
| Стилизация | Графичный 2D game / dark-fantasy comic portrait — выразительные утрированные черты, крупные читаемые формы. Не photoreal, не extreme chibi, не полуреалистичный бестиарий |
| Кадр юнитов/врагов | **Поясной / torso–waist-up mid portrait** — крупно в кадре. **Не full-body** (иначе портрет мельчает) |
| Рамка панели | Весь силуэт, белый контур, оружие, рога, крылья — **строго внутри** панели с небольшим отступом; ничего не вылезает за край и не пересекает gutter |
| Тона | Ясный локальный цвет, хорошая насыщенность и контраст — без неона / candy |
| Детализация | Выше среднего, графичная: швы, ржавчина, руны, пластины; мех/грязь = stylized shapes |
| Фон | **Упрощённый тематический** под юнита (пещера, подземелье, лес, огонь, болото, замок…) — стилизованный, читаемый, на втором плане. Не плоский серый smoke-wash |

### Эталон (утверждён)

- **Хорошо:** как `enemy_portrait_example.jpg` — поясные портреты, **тонкий** белый контур, чистые тёмные линии, hard cel, тематический простой фон, крупное лицо/торс  
- **Плохо:** толстый белый sticker-border; full-body sticker на пустом/дымном фоне; полуреалистичный мех; мелкие фигурки в полный рост  

### Чего избегать

- Photoreal / 3D / CGI / semi-realistic wildlife  
- Full-body по умолчанию для врагов/юнитов/бестиария  
- **Толстый / жирный белый outer outline** (chunky sticker stroke) — эталон: тонкая ровная линия  
- Выход юнита за рамку панели / обрезка рогов-оружия краем / пересечение gutter  
- Серо-зелёный smoke / fog wash без структуры  
- Extreme chibi / neon / candy-oversaturation  
- Текст, watermark, UI  

## Портреты героев

| Параметр | Решение |
|----------|---------|
| Кадр | Bust / chest-up (ещё крупнее, чем у врагов) |
| Стиль | Тот же toon + **тонкий** белый контур, что у эталона врагов |
| Фон | Простой тематический или тёмный stylized — без дымного wash |
| Сеттинг в костюме | Фэнтези + лёгкий стимпанк (магия > tech) |

## Портреты врагов / юнитов / бестиарий — LOCKED

| Параметр | Решение |
|----------|---------|
| Кадр | **Waist-up / torso mid-shot** — голова и торс крупные, оружие читается у плеч/груди |
| Угол | 3/4 или почти анфас |
| Фон | Свой упрощённый environment на панель (стилизованный), согласованный с типом врага |
| Лист | 3×3 = 9 **уникальных** дизайнов |

## Иконки способностей

| Параметр | Решение |
|----------|---------|
| Кадр | Один эффект по центру |
| Стиль | Toon + **тонкий** белый контур (не толстый) |
| Фон | Плоский тёмный solid (без сцены) |
| Акцент | cyan / orange / sand-gold / violet - яркие, не неоновые |

## Иконки предметов (лут / экипировка)

Тот же визуальный язык, что у портретов и ability icons. Промпты: skill `art-item` (обязательны **ячейка** + **редкость**).

| Параметр | Решение |
|----------|---------|
| Кадр | Один предмет по центру, крупно, orthographic / лёгкий 3/4 |
| Стиль | Toon + **hairline** белый контур (~1px относительно панели, не 2–3px и не толстый marker) |
| Направление | **Fantasy-first** classic / dark fantasy loot. Не historical medieval catalog и не steampunk-first; tech/латунь только по явной теме |
| Промпт | Не называть игру / проект / Style Bible в тексте для Gemini - только описание вида |
| Фон | Плоский тёмный solid (инвентарь, без сцены) |
| Редкость | Чем выше - тем сложнее, необычнее и детальнее сам предмет. Цветная рамка редкости - **только UI**, не рисуется в иконке |
| Лист | 3×3: по умолчанию 9 **разных** предметов одной ячейки и редкости (batch для лута) |

### Редкость предметов (канон игры)

| Редкость | UI-рамка | Сложность иконки (кратко) |
|----------|----------|---------------------------|
| обычная | белая | простой силуэт, минимум декора |
| необычная | зеленая | лёгкий акцент, чуть лучше крафт |
| магическая | синяя | руны / слабое свечение / зачарование |
| редкая | желтая | богатые материалы, запоминающийся силуэт |
| эпическая | фиолетовая | плотная, но читаемая детализация, сильный fantasy-образ |
| легендарная (оранжевая) | оранжевая | уникальный силуэт, пик детали и магии, без грязной каши |
| сет / комплект | бирюзовая | epic-leaning + общий мотив комплекта на самом предмете |

## Environment

Стилизованный фон арены (средневековье + стимпанк), не конкурирует с сеткой юнитов.

## Типы ассетов

### `portrait` (герои)
- Bust/chest-up · лист 3×3  
- `assets/art/portraits/{id}.png`

### `unit_card` / враги / бестиарий
- **Waist-up portrait** (как эталон), НЕ full-body  
- Лист 3×3  
- `assets/art/units/{id}_card.png` или кроп портрета врага

### `ability_icon`
- Лист 3×3 · `assets/art/skills/{ability_id}.png`

### `item_icon`
- Лист 3×3 · `assets/art/items/{slot}/{id}.png`  
- Промпты: `.cursor/skills/art-item`

### `environment`
- Фон арены  

## Палитра

- Персонажи: ясные локальные цвета (green skin, bone, purple robes, fire orange…)  
- Фоны: тематические, чуть спокойнее персонажа, но не серый smoke  
- Стимпанк-материалы: латунь/медь с теплом
