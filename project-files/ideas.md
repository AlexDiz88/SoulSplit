# Идеи: мотивация ходить по разным регионам и локациям

**Канон (одобрено):** `design/meta/LOCATION_DIVERSITY.md` + правило `.cursor/rules/location-diversity.mdc`.
Ниже - исходный мозговой штурм; часть пунктов отвергнута (диминишинг XP/лута/угрозы, аспект-бонусы локаций, блок доступа, гарант-предметы). Для дизайна и кода опирайся на канон.

## Проблема

На карте много регионов. У каждого несколько локаций с разными врагами и уровнем угрозы. При этом многие регионы пересекаются по уровню врагов и общему уровню угрозы.

В одну и ту же локацию игрок может ходить сколько угодно раз.

Риск: фармить одну "Северную дорогу" с 1 по 6 уровень и пропустить "Дубовую рощу", "Руины" и другие регионы того же tier.

Цель: игрок изучает новые локации и врагов.

Специфика Soul Split:

- мгновенные перемещения между регионами (трение дороги не работает)
- иерархия: провинция → регион → локация
- повторяемые вылазки
- доска объявлений в ратуше
- аспекты, пулы врагов, лут по `itemLevel`

Ключевой вывод: нужны **pull-рычаги** ("туда выгоднее / интереснее / нужно"), а не friction ("отсюда далеко").

## Рычаги

### Лут и прогресс экипа

1. **Уникальный лут региона** - аффиксы / темы предметов только из "Дубовой рощи" или "Руин" (нежить-резисты, зверь-крит и т.д.).
2. **Уникальный лут локации** - внутри региона тоже разброс ("Катакомбы" ≠ "Двор").
3. **Материалы крафта / алхимии по биому** - без рощи нет коры, без руин нет костяной пыли.
4. **Рецепты / схемы** - дропают или открываются только в новых местах.
5. **Сеты "по земле"** - 2-3 предмета с бонусом, если собраны из разных регионов одного уровня.
6. **Ротация "горячего" дропа** - сегодня бонусный вес rare на роще, завтра на руинах (без бана старого места).

### Квесты и нарратив

7. **Квесты, привязанные к региону/локации** - без визита прогресс не идёт (не "убей N любых бандитов").
8. **Цепочки через несколько регионов** - дорога → роща → руины, одна история.
9. **Суточные / сменные объявления ратуши** - доска тасует цели по разным точкам карты.
10. **Контракты на "незнакомых" врагов** - награда выше, если kind ещё не убивали / мало убивали.
11. **Репутация с фракциями / землями** - торговцы, скидки, уникальные квесты за "заслуги" в регионе.

### Бестиарий и коллекционирование

12. **Кодекс врагов** - запись + награда за первого убитого вида (у нас уже сильный бестиарий).
13. **Коллекция портретов / карточек** - "увидеть" врага = мотивация зайти в новую локацию.
14. **Достижения "зачистил все локации региона"** - косметика, титул, разовый сундук.
15. **Первый визит / discovery XP** - разовый бонус за открытие локации (не за фарм).

### Бой и билды (под аспекты)

16. **Разный геймплей пулов** - бандиты ≠ нежить ≠ звери: другие темпы, контроль, угрозы.
17. **Контр-аспекты / резисты по биому** - в роще выгоднее Зверь, в руинах другой аспект; фарм одной дороги режет билды.
18. **Уникальные элиты / мини-боссы локации** - только тут, с особым лутом или способностью.
19. **Механики арены локации** - ловушки, туман, укрытия (не только другой спрайт фона).

### Экономика и "почему не одну точку"

20. **Диминишинг фарм-эффективности** - после N побед подряд в одной локации режет золото/XP/вес rare (мягко, видно в UI).
21. **XP уже почти готов** - у нас `|Δ| > 3 → 0`; усилить ощущение: на одной дороге быстро "выжимаешь" полосу уровней, соседние регионы того же tier остаются оптимальными.
22. **Золото / vendor-товары региональные** - скупщик или НПС у точки продаёт то, чего нет в Грейстоуне.
23. **Лимит "свежести" угрозы** - повторный заход в ту же локацию без отдыха/смены цели даёт более бедную пачку (опционально).

### Карта, UI, ощущение мира

24. **Видимые "голодные" маркеры** - на карте иконки: новый квест, неоткрытая локация, недобитый кодекс, горячий лут.
25. **Слухи в городе** - короткие хуки в ратуше/рынке: "в роще видели…", ведут взгляд на точку.
26. **Прогресс исследования провинции** - полоска "% локаций посещено" с порогами наград.
27. **Сюжетные гейты мягкие** - не блок стены, а "следующая глава открывается после визита X" (квест/лор/портрет НПС).

### Мета / долгосрочка

28. **Еженедельные цели провинции** - "побывай в 3 разных регионах", "убей по 1 элите из 3 биомов".
29. **Разблокировки хаба** - новый НПС, слот тайника, косметика города за исследование окраин.
30. **PvE-рейтинг / сезон "землепроходец"** - очки за разнообразие, не за киллы в одном споте.

## Что особенно важно при телепорте

| Работает слабо | Работает сильно |
|---|---|
| Усталость от пути, время в пути | Уникальный лут / материалы по региону |
| "Далеко, не хочу идти" | Квесты и кодекс с привязкой к месту |
| Хардлок "сюда нельзя" рано | Разный бой + видимые маркеры на карте |
| Наказание за повтор | Награда за **первое** и за **разнообразие** |

Игрок всё равно может фармить Северную дорогу - и это ок. Задача не запретить, а сделать так, чтобы **пропуск рощи/руин ощущался как упущенный лут, враг, квест и кусок билда**.
