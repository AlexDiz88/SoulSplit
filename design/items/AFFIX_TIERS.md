# Тиры аффиксов

Канон генерации значений на предметах (модель A). Код: `src/items/tiers.ts`, `src/items/affixCatalog.ts`.

## Кап

Герой / монстры / предметы: уровень **1…20** (v1).

## Ранги

| index | id | base ilvl |
|------:|:---|:----------|
| 0 | F | 1-2 |
| 1 | E | 3-4 |
| 2 | D | 5-6 |
| 3 | C | 7-8 |
| 4 | B | 9-10 |
| 5 | A1 | 11-12 |
| 6 | A2 | 13-14 |
| 7 | A3 | 15-16 |
| 8 | A4 | 17-18 |
| 9 | A5 | 19-20 |

Чистого `A` нет - сразу `A1…A5`. После капа 20 можно добавить `S1…S5`.

## Оффсет

База одинакова у пары уровней (5 и 6 → D), но окно оффсетов разное:

- **Низ пары** (нечётный ilvl): `-2, -1, 0, +1`
- **Верх пары** (чётный ilvl): `-1, 0, +1, +2`
- `±3` запрещены

Так предметы смежных уровней одной "буквы" всё же отличаются по потолку/полу силы.

## Значение

У каждого аффикса 10 диапазонов `[min, max]`. Ролл `q` - среднее двух `random` (чаще середина, края живые). God-roll по всем аффиксам разрешён (лимита силы между модами нет).

## UI

Всегда в тултипе: `+52 здоровья [48-66] D`.
