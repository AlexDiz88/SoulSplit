# Цепная молния

- **Аспект:** Молния
- **Описание:** Разряд бьёт выбранного врага и перескакивает на соседей по клетке, ослабевая с каждым прыжком.
- **Кулдаун:** 7.5 с
- **Затраты по мане:** 36
- **Тип применения:** цель
- **Зона применения:** нет
- **Тип эффекта:** урон
- **Числа:**
  - 36 урона молнии по первой цели
  - до 2 прыжков на других врагов в соседней клетке (включая по диагонали): по 22 урона молнии за прыжок
  - одна цель не может получить разряд дважды за один каст
