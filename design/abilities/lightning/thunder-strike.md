# Громовой удар

- **Аспект:** Молния
- **Описание:** С неба бьёт одиночный разряд в выбранного врага. На цели копится шок: каждый заряд делает следующие удары молнии по ней ощутимее.
- **Кулдаун:** 5 с
- **Затраты по мане:** 28
- **Тип применения:** цель
- **Зона применения:** нет
- **Тип эффекта:** урон, дебафф
- **Числа:**
  - 40 урона молнии по выбранному врагу
  - шок 5 с: +15% урона от следующей способности молнии по этой цели за каждый стак, до 3 стаков
- **Доп:** повторный шок добавляет стак (максимум 3) и обновляет длительность до 5 с
