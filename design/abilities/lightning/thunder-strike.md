# Громовой удар

- **Аспект:** Молния
- **Описание:** С неба бьёт одиночный разряд в выбранного врага. Цель накопляет статическое напряжение: следующая способность молнии по ней бьёт сильнее.
- **Кулдаун:** 5 с
- **Затраты по мане:** 28
- **Тип применения:** цель
- **Зона применения:** нет
- **Тип эффекта:** урон, дебафф
- **Числа:**
  - 40 урона молнии по выбранному врагу
  - шок 5 с: следующая способность молнии по этой цели наносит на 35% больше урона (один раз, не стакается)
