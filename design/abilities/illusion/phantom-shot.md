# Призрачный выстрел

- **Аспект:** Иллюзии/Эфир
- **Описание:** Сгусток эфира бьёт в выбранного врага и оставляет в глазах ложный след: следующий его удар по кому-либо не попадает.
- **Кулдаун:** 5 с
- **Затраты по мане:** 26
- **Тип применения:** цель
- **Зона применения:** нет
- **Тип эффекта:** урон, дебафф
- **Числа:**
  - 38 урона эфиром по выбранному врагу
  - следующая автоатака этого врага промахивается (срывается после одной попытки)
