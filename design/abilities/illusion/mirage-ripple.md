# Зыбь миражей

- **Аспект:** Иллюзии/Эфир
- **Описание:** По полю боя проходит волна эфира: враги видят десятки копий друг друга и на миг теряют ритм атаки.
- **Кулдаун:** 8.5 с
- **Затраты по мане:** 34
- **Тип применения:** все враги
- **Зона применения:** нет
- **Тип эффекта:** урон, дебафф
- **Числа:**
  - 22 урона эфиром каждому врагу на сетке
  - интервал автоатаки ×1.25 на 4 с у каждого поражённого врага
