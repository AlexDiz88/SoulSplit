# Приказ

- **Аспект:** враги
- **Описание:** Главарь отдаёт короткий приказ выбранному союзнику. Тот бьёт сильнее, пока действует приказ.
- **Кулдаун:** 8 с
- **Затраты по мане:** нет
- **Тип применения:** союзник
- **Зона применения:** нет
- **Тип эффекта:** бафф
- **Числа:**
  - урон атаки выбранного союзника ×1.2 на 5 с
