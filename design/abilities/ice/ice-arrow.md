# Ледяная стрела

- **Аспект:** Лёд
- **Описание:** Выпускает ледяную стрелу, наносящую 38 ед. урона льдом. Сковывает цель холодом, снижая скорость атаки.
- **Кулдаун:** 4.5 с
- **Затраты по мане:** 22
- **Тип применения:** цель
- **Зона применения:** нет
- **Тип эффекта:** урон, дебафф
- **Числа:**
  - 38 урона льда
  - скорость атаки цели снижена на 35% на 3 с
