# Ледяная стрела

- **Аспект:** Лёд
- **Описание:** Выпускает ледяную стрелу, наносящую 38 ед. урона льдом. Сковывает цель холодом, увеличивая интервал ее автоатаки в 1.35 раза на 3 сек.
- **Кулдаун:** 4.5 с
- **Затраты по мане:** 22
- **Тип применения:** цель
- **Зона применения:** нет
- **Тип эффекта:** урон, дебафф
- **Числа:**
  - 38 урона льда
  - интервал автоатаки ×1.35 на 3 с
