# Бросок молота

- **Школа:** Сила
- **Описание:** Герой швыряет молот во врага в ближнем ряду. Тяжелый удар сбивает цель с ног, и та не может действовать.
- **Кулдаун:** 5 с
- **Затраты по мане:** 28
- **Тип применения:** цель
- **Зона применения:** нет
- **Тип эффекта:** урон, контроль
- **Числа:**
  - 45 физического урона
  - стан 2.2 с
