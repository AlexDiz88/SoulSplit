# Звериный укус

- **Аспект:** Дух Зверя
- **Описание:** Дух хищника вонзается в выбранного врага и оставляет метку добычи: по помеченной цели легче бить другими приёмами зверя.
- **Кулдаун:** 5 с
- **Затраты по мане:** 26
- **Тип применения:** цель
- **Зона применения:** нет
- **Тип эффекта:** урон, дебафф
- **Числа:**
  - 42 физического урона по выбранному врагу
  - метка добычи 6 с: способности аспекта Дух Зверя по этой цели наносят на 25% больше урона
