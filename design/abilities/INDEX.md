# Каталог способностей

Сюда пишет скилл `create-ability`. Карточки кластера `враги` также может добавлять `create-enemy`, когда юниту сразу нужна способность. Гримуар в игре читает карточки из папок аспектов. Бой по-прежнему живёт своим кодом.

Лимита на число способностей при разработке нет.

Крючок - тип применения, есть ли урон, и решение. Для аспектов героя по крючку видно копию. У кластера `враги` похожие крючки допустимы.
