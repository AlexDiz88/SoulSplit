# Каталог способностей

Сюда пишет скилл `create-ability`. Гримуар в игре читает карточки из папок школ. Бой по-прежнему живёт своим кодом.

Лимита на число способностей при разработке нет.

Крючок - тип применения, есть ли урон, и решение. По нему видно копию, не открывая файл.
