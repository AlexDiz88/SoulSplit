# Дыхание дракона

- **Школа:** Огонь
- **Описание:** Герой выдыхает пламя веером перед собой. Огонь накрывает середину ближнего ряда и на два ряда вглубь расходится во всю ширину. До дальнего ряда пламя не достает.
- **Кулдаун:** 6.5 с
- **Затраты по мане:** 32
- **Тип применения:** зона
- **Зона применения:** веер от героя, досягаемость 3 ряда
- **Тип эффекта:** урон
- **Числа:**
  - 34 урона огня на каждую задетую клетку

## Зона

якорь: от героя
урон по клеткам: одинаковый

```
    0 1 2 3
0   . . . .
1   # # # #
2   # # # #
3   . # # .
```

Ряд 3 - ближний к герою. Все `#` по 34 урона.
