# Каталог врагов (бестиарий)

Сюда пишет скилл `create-enemy`. По запросу он же может завести способность в `design/abilities/enemies/` и прописать её id в карточке. Бестиарий в игре читает карточки из папок групп / регионов. Бой живёт в `src/combat/enemies.ts` (`ENEMY_KINDS`).

Новая карточка - статус `черновик` (в код боя не попадает). Статус `одобрено` = юнит **должен** быть в `ENEMY_KINDS` + портреты. `отказ` / `под вопросом` в боевой пул не входят. Генератор сам статусы одобренных карточек не меняет.

Крючок - reach / ряд и роль/решение для навигации. Похожие юниты в разных группах (и даже рядом) допустимы: лор, квесты и разнообразие фракций важнее уникальности механики.

Базовый уровень - то, что видно в бестиарии. В бою уровень = base ±2 (кап 1-20), статы масштабируются от оффсета.
