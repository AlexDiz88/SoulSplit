# Каталог врагов (бестиарий)

Сюда пишет скилл `create-enemy`. Бестиарий в игре читает карточки из папок групп / регионов. Бой по-прежнему живёт своим кодом в `src/combat/enemies.ts`.

Новая карточка - статус `черновик`. Статусы `одобрено`, `отказ`, `под вопросом` генератор не меняет.

Крючок - роль, дистанция / ряд, и чем враг отличается от соседей по группе. По нему видно копию, не открывая файл.

Базовый уровень - то, что видно в бестиарии. В бою уровень = base ±2 (кап 1-20), статы масштабируются от оффсета.
