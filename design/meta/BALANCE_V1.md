# Баланс v1 (уровни 1-3)

Ориентиры для плейтеста. Цифры XP - в `src/meta/progression.ts`.

## Герой

| Ур. | maxHp | maxMana | manaRegen | оружие |
|---|---|---|---|---|
| 1 | 300 | 100 | 4 | Тренировочный клинок 20-30 / 1.5с |
| 2 | 335 | 105 | 4 | +лут |
| 3 | 370 | 110 | 4 | +лут |

Level-up: `+35 HP`, `+5 mana`; на ур. 5/10/... ещё `+0.5 manaRegen`.

Кап уровня: **20**.

XP до следующего (круглые): 800 / 1400 / 2200 / 3200 / … (таблица `XP_TO_NEXT`).

Equal-level убийств на уровень: `28 + 9*(L-1)` (1→2: 28, 5→6: 64, 19→20: 190).

XP за килл: `baseKillXp(enemyLevel) * mult(Δ) * (elite ? 1.5 : 1)`; `|Δ| > 3` → 0.

Квесты: ≤10% полосы `questLevel`; оверлевел сдачи `|Δh|`: ≤2 полный, 3 → ×0.35, ≥4 → 0.

## Северная дорога (ilvl 1-3) - C2

- Пачка: **бюджет угрозы** (`encounter.threatBudget`) + опциональный `guarantee`, добор из `pool`
- Стоимость юнита: `(threat ?? baseLevel) * (threatMult ?? 1) * eliteMult + (level - baseLevel)`; элита ×1.25 к угрозе; добор может превысить бюджет до +10%
- У стены `[3, 6]` (гарантия Бродяга+Швыряла); Перекрёсток `[8, 12]`; Перелесок `[10, 14]`; Лагерь бандитов `[15, 20]` + Главарь
- XP: по убитым (уровень + элита), не от зоны; герой 1, пачка ~4 ур.1 → ~7 боёв до 2 ур. без квестов
- Скейл врагов: у каждого свой `baseLevel`; в бою уровень = base ±2 (кап 1-20), `hp/atk` от оффсета (~+12% HP / +10% atk за уровень). `itemLevel` локации - для лута, не для HP врагов

## Лут - C3

- Outskirts rare вес **9** (было 6), чаще второй дроп
- Ранние аффиксы maxHp / weaponAtk / abilityDmg чуть сильнее; тир ilvl 4 для перехода в Руины

## Руины (ilvl 3-4) - D1/D2

- Пачка: Двор бюджет `[10, 18]`, Катакомбы `[14, 24]`
- Элита: **5%/8%** на врага, `hp ×1.6`, `atk ×1.25`, золотая рамка; угроза элиты ×1.25; XP элиты ×1.5

## Экономика - D3

- Золото за победу: `(8 + kills * 2) * zone.itemLevel`
- Скупщик: `ilvl * rarityMult` (common 5 … epic 40)

## Цели ощущения

- Первый бой: 40-90 сек при среднем плее
- После 2-3 побед экип заметно меняет выживаемость или урон
- Поражение на старте возможно, но не каждый бой
- C4: после первого похода "В поход" сразу в последнюю зону; на поражении экип не блокируется

## Чеклист тюнинга

1. Слишком сложно на ур.1 → снизить `threatBudget` у стены / Перекрёстка
2. Слишком легко → поднять бюджет или guarantee ключевых локаций
3. Лут слабый → веса rare / early affix tiers
4. Темп уровней → `XP_TO_NEXT` / `killsPerLevel` / таблица `killXpMult` в `progression.ts`
