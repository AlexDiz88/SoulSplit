# Мотивация посещать разные регионы и локации

**Статус: одобрено.** Канон для дизайна карты, квестов, лута, репутации и маркеров на карте провинции.

См. также: [WORLD_HIERARCHY.md](./WORLD_HIERARCHY.md), [WORLD_LORE.md](./WORLD_LORE.md).

## Цель

Игрок изучает новые регионы, локации и врагов, а не фармит один регион (например "Северную дорогу") через весь свой уровень угрозы, пропуская соседние ("Дубовая роща", "Руины") с похожим tier.

Повторять уже открытую локацию сколько угодно раз - **можно и ок**. Задача не запретить фарм, а сделать пропуск других мест упущенной выгодой.

## Главный принцип

Только **pull-мотивация**: бонусы, награды, квесты, торговцы, маркеры в других местах.

Нельзя толкать игрока **punish-мотивацией**: штрафы, урезание награды/угрозы, блокировки уже доступного.

Специфика мира: **мгновенные перемещения** между регионами. Трение дороги (время в пути, усталость от перехода) как рычаг **не использовать**.

## Можно использовать

### Лут и крафт

- **Уникальный лут региона / локации** - свои таблицы, веса, темы аффиксов, пулы материалов. Разные места дают разный *профиль* дропа.
- **Особый лут с мобов для крафта / улучшений** - биомные материалы (кора рощи, костяная пыль руин и т.п.), без которых не закрыть крафт/апгрейды.
- Весь экип и свойства предметов по-прежнему **генерируются случайно** по правилам таблиц. "Уникальный лут места" = уникальный **пул / веса / материалы**, не фиксированный именной предмет с гарантированными статами.

### Квесты и контракты

- **Квесты, привязанные к региону / локации** - прогресс требует визита конкретного места (не "убей N любых врагов где угодно").
- **Цепочки через несколько регионов** - одна история ведёт дорога → роща → руины (или иной маршрут по карте).
- **Суточные / сменные мини-контракты** на доске объявлений ратуши. Могут повторяться со временем, но **нельзя два раза подряд** назначать контракт в одну и ту же локацию.
- **Контракты на конкретных боссов / мини-боссов**. Босс привязан к региону и локации - контракт сам тянет игрока туда.

### Первые прохождения и репутация

- **Особый сундук с наградами при первом прохождении** региона (или согласованного этапа). Разовая pull-награда за открытие / первую зачистку, не наказание за повтор.
- **Репутация с фракциями / торговцами**: убийства врагов в определённом регионе качают репутацию у связанного торговца (скидки, бонусы, ассортимент).

### Карта и полевые точки

- **"Крик о помощи"** - временный спец-маркер рядом с регионом прямо на карте провинции, с таймером окончания. Даёт бонусы при успехе. Задание принимается **автоматически** и **может быть провалено** по таймеру / условиям.
- **Спец-торговец в локациях** - особые товары / функции, которых нет в городе-хабе. Доступен после прохождения нужного этапа локации / региона.

### Отложенные рычаги (канон "на будущее")

- **Достижения** - пока далёкая концепция; как способ завлечь в конкретную локацию допустимы позже.
- **Слухи в таверне** - интересный подход (хуки на точки карты). Реализация ещё не зафиксирована; идею сохранить, в ближайший слой контента не внедрять без отдельного решения.

## Нельзя использовать

- **Снижение опыта / лута / золота** при повторных прохождениях одной локации - даже временное. Мотивировать сменой локаций за счёт **бонусов в других местах**, не за счёт урезания эффективности в одной.
- **Уменьшение числа врагов / размера угрозы** как наказание или soft-lock за повторный фарм.
- **Бонусы или штрафы аспектам** в конкретных локациях / регионах ("в роще Зверь сильнее", "в руинах Воздух слабее").
- **Конкретные (не рандомные) предметы зоны** с гарантированными свойствами. Весь лут экипа в игре генерируется случайно по правилам. Недопустимо: "здесь всегда падает клинок с такими-то аффиксами".
- **Запрет / блок уже открытой или доступной локации** - в том числе после большого числа повторных прохождений.

---

## Краткие правила для дизайна контента

1. Спрашивай: "что игрок **получит**, если пойдёт туда?" - не "что он **потеряет**, если останется здесь?".
2. Повтор локации остаётся валидной стратегией; разнообразие должно быть **выгоднее или интереснее**, не обязательным через nerf.
3. Привязка к месту у квестов, боссов, материалов, репутации и маркеров - главный рабочий набор при телепорте.
4. Первый сундук / discovery-награда - ок; диминишинг за повтор - нет.
5. Слухи в таверне и достижения - в бэклог, не блокер текущего контента.
