# Тайминг способностей в бою (канон)

Статус: **одобрено**. Связано с карточками (`castTime` в дефе), боем (`Battle.ts`, `Unit.ts`) и VFX (`src/vfx/premium/*`).

## Две оси

1. **Класс активации** - мгновенная или с подготовкой (каст).
2. **Канал доставки эффекта** - когда именно в коде наносится урон, вешаются статусы и считается промах.

Игрок видит только класс активации в карточке (`время каста N с` или без строки). Канал доставки - правило реализации, его можно кратко описать в `extra`, если важен промах или задержка удара.

## Класс: мгновенная способность

`castTime` в каталоге **нет** или `null` или `0`.

- В момент подтверждения цели: списание маны, старт кулдауна способности, GCD, снятие выбора с панели.
- **Автоатака не останавливается** из-за этой способности. Длинный VFX после применения - норма, он не должен замораживать шкалу автоатаки.
- Логика «ударил / наложил» может быть **не** в тот же кадр: снаряд, рывок, волна по полю - см. каналы доставки.
- Старт анимации применения (вылет снаряда, вспышка, рывок) - **сразу** после подтверждения, без отдельной полосы подготовки у героя.

## Класс: каст (подготовка)

`castTime` в каталоге **> 0** (и то же значение в `combat.effects.castTime`).

- После подтверждения цели герой входит в **подготовку** на `castDuration(castTime, castSpeed)` секунд.
- На время подготовки **автоатака останавливается** (таймеры не копят лишние удары, как у врага при касте).
- Под портретом героя показывается **отдельная полоса каста** (не полосы автоатаки): имя способности, прогресс 0..1.
- **Анимация способности и доставка эффекта** начинаются **только после** окончания подготовки. Дальше - те же правила, что у мгновенной (включая снаряды с уроном по прилёту).
- Визуальный «заряд» в premium-VFX **не заменяет** полосу каста: фаза подготовки - UI и логика боя; VFX может дублировать настроение, но таймер каста живёт в `Unit.cast` / бое, не только в твине VFX.

Игроку в карточке пишем `время каста N с`, без пояснения про автоатаку (баланс).

## Каналы доставки эффекта

Выбери **один** основной канал при переносе в бой. Смешивай осознанно (например, каст + снаряд).

| Канал | Когда применяется урон/статусы | Промах |
|--------|--------------------------------|--------|
| `instant_frame` | В кадр старта фазы применения (после каста, если есть) | По правилам цели: враг на клетке / `targetMode: enemy` |
| `projectile_impact` | В колбэке `onImpact` / `onArrive` полёта снаряда | `occupantAtImpact` / `sameEnemyOnCell`: пустая клетка - «ПРОМАХ», без урона |
| `zone_after_vfx` | После `await` зонального VFX (конус, дыхание): обход клеток узора | Кто стоит на клетке **в момент удара**, не при прицеливании |
| `zone_snapshot` | Сразу по списку целей в кадр удара (редко) | Только если карточка явно говорит «мгновенный залп» |
| `multi_callback` | Несколько колбэков (лавина по врагам, цепь молний) | Для каждой цели свои правила |
| `self_buff_sync` | Статус герою до или в начале VFX, урон по врагам не нужен | - |

### Снаряд (эталон)

`ice_arrow`, `fireball`, `hammer_throw`:

1. Прицел: `aimCell` в момент **старта фазы применения** (после каста).
2. VFX летит к координатам клетки.
3. Урон и дебафф - **только** в колбэке прилёта.
4. Проверка: `occupantAtImpact(aim, impact)` или `sameEnemyOnCell` для режима по юниту.

### Мгновенный удар по цели

`sever_artery`, `ice_shield`: урон и статусы в кадр применения; `await` VFX только для картинки.

### Самобафф

Щит, haste, titan_might: статус **до** или синхронно с началом VFX, чтобы игрок сразу получил механику, даже если спрайт ещё дорисовывается.

## Очередь и GCD

- Пока идёт **подготовка каста** или залочен **канал применения** (см. технический долг в скилле `ability-combat`): повторный клик по способности ставится в `pendingCast`.
- GCD общий для героя после подтверждения.

## Враги

У врагов подготовка уже через `Unit.beginCast` и полосу на портрете. Герой должен вести себя симметрично по смыслу (отдельная полоса каста, автоатака стоит только на подготовке).

## Связь с карточкой

- `castTime` только в дефе каталога + `combat.effects.castTime`.
- В `extra` указывай только то, что игрок должен знать: промах снаряда, удар после долёта, зона бьёт кто стоит в конце волны, прерывание каста врага и т.д.

## Технический долг (известные отступления)

До рефактора `Battle.casting`:

1. Флаг `casting` держится на весь `resolveAbility`, включая длинный VFX - **мгновенные** способности временно тоже блокируют автоатаку. Целевое поведение - блокировать только фазу `castTime`.
2. У героя нет отдельной полосы каста; `avalanche` частично крутит подготовку внутри `AvalancheVfx`, а не через `hero.beginCast`.
3. `castDuration()` из `formulas.ts` для героя в бою пока не вызывается.

Новые способности проектируем по канону; при правке старых - по возможности подтягиваем к канону.
