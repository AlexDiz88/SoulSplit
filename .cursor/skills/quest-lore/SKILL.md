# Quest Lore - Soul Split

Пишет **художественное, лорное** описание задания в духе текстов квестов WoW.
Механику квеста не выдумывает и в прозу не тащит.

## Когда срабатывает

**Автоматически** (прочитай этот скилл и выполни шаг "Лор-текст"):

- пользователь просит добавить / создать / обновить квест;
- правишь `design/quests/**`, `src/quests/definitions.ts`, `QuestDef.description`, карточку или текст ратуши/журнала;
- в задаче есть новое или изменённое задание, у которого ещё нет лорного `description` или оно техническое.

**Вручную:** пользователь указал название квеста - перепиши **только** лор-текст этого задания.

Примеры ручного вызова:

- `/quest-lore Зачистка бандитов`
- `quest-lore cull-bandits`
- `quest-lore cull_bandits`

Разбор ручного вызова:

1. Убери ведущий `/quest-lore` или `quest-lore`.
2. Остаток - название (русское имя), kebab-id карточки или `code_id`.
3. Имя пустое - один вопрос, без генерации.

## Обязательное чтение перед текстом

Каждый раз, даже при ручном вызове:

1. [WORLD_LORE.md](../../../design/meta/WORLD_LORE.md) - **целиком**.
2. [WORLD_HIERARCHY.md](../../../design/meta/WORLD_HIERARCHY.md) - имена мест.
3. [style.md](style.md) - тон и антипримеры.
4. [INDEX.md](../../../design/quests/INDEX.md) и карточку квеста `design/quests/{id}.md`, если есть.
5. При необходимости: связанные враги/регион в `design/enemies/`, описание зоны в `src/meta/zones.ts`.

Не противоречь канону. Новый устойчивый факт лора (имя чиновника, причина войны банд, история руин), который должен жить дольше одного квеста, **допиши** короткой строкой в журнал `WORLD_LORE.md`.

## Что обновлять

Один и тот же лор-текст в двух местах:

1. Проза в конце карточки `design/quests/{kebab-id}.md` (после списка Цель/Награда).
2. Поле `description` в `src/quests/definitions.ts`.

Список **Цель** / **Награда** / `objectives` / `rewards` / `label` **не** переписывай этим скиллом, если задача не про механику. Крючок в INDEX можно слегка уточнить по смыслу, без техники засчёта.

## Как писать

1. Возьми факты квеста (кто даёт, где, против кого, зачем городу) из карточки/кода/запроса.
2. Разверни в историю места и ставки - эталон и запреты в [style.md](style.md).
3. В `description` - только лор. Числа целей, "любой X засчитывается", group_id, награды цифрами - **запрещены**.
4. Типографика проекта: `-` и `"`, без `—` / `–` / `«»`.
5. После записи покажи пользователю итоговый текст кратко (цитатой).

## Разделение лора и механики

| Место | Содержимое |
|---|---|
| `description` + проза карточки | атмосфера, предыстория, ставка, призыв |
| **Цель** / `objectives[].label` | короткая цель для игрока ("Убить бандитов") |
| **Награда** / `rewards` | опыт, золото, предмет |

Плохо в description: `любой бандит засчитывается`, `убить 15`, `group_id: bandits`.
Хорошо: дорога, страх обозов, просьба ратуши вернуть тракту имя пути.

## Не делать

- Не подменяй канон `WORLD_LORE.md` ради красивой фразы.
- Не пиши лор, если квест ещё без имени/сути - сначала уточни задачу квеста.
- Не вызывай этот скилл для балансных правок чисел без смены смысла задания (лор можно не трогать).
