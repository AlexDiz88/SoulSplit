# Аспекты

`aspect_id` - папка в `design/abilities/` и технический id в коде.

## Чем аспект отличается

Решение новой способности бери отсюда. Соседний аспект не перекрашивай.

- **Алхимия** - склянки, реакции, кислота, трансмутация уже висящего эффекта в другой. Тип урона: кислота. Не яд растений и не кровь.
- **Аркан** - сырая магия: щели в пространстве, щит из маны, нестабильный снаряд, телепорт цели на клетку. Тип урона: аркан. Не стихия.
- **Воздух** - порыв, отбрасывание на клетку, скорость атаки, пыль. Тип урона: воздух. Не молния и не полёт-рывок скрытности.
- **Дух Зверя** - тело зверя: рывок, укус, метка добычи, дух рядом с героем. Тип урона: физический. Не лук охоты.
- **Земля** - тяжесть, броня, шип из клетки, удар по площади который трудно сдвинуть. Тип урона: земля. Не корни природы.
- **Иллюзии/Эфир** - ложная цель, промах врага, эфир бьёт клетку где никого "нет", копия эффекта. Тип урона: эфир. Глаза врёт иллюзия, волю ломает Разум.
- **Колдовство** - проклятие, сглаз, связка двух врагов, порча которая копится и срывается. Тип урона: порча. Не трупы некромантии и не субстанция тьмы.
- **Кровь** - плата своим здоровьем, кровотечение, лечение от раны, сила пока герой ранен. Тип урона: кровь.
- **Лёд** - темп боя: интервал атаки, заморозка на месте, хрупкость (следующий удар сильнее). Тип урона: лёд.
- **Механика** - поставленное устройство на клетку: турель, капкан-механизм, заряд с перезарядкой устройства. Единственный аспект, где уместен механизм, а не чистая магия. Тип урона: механика. Не магическая ловушка охоты.
- **Молния** - прыжок на другую клетку, цепь, шок (следующее умение молнии по этой цели сильнее). Тип урона: молния. Не ветер.
- **Некромантия/Смерть** - жизнь цели, труп на клетке, подъём, страх смерти. Тип урона: смерть. Не кровотечение и не тень.
- **Огонь** - жар, горение, взрыв, след на клетках. Тип урона: огонь.
- **Природа** - живое: лоза, корень, регенерация, растительный яд, удержание на клетке. Тип урона: природа или яд. Не камень земли.
- **Разум** - страх, очарование, обмен цели, оглушение воли. Тип урона: разум, часто без урона. Не обман картинки.
- **Свет** - лечение, снятие одного дебаффа, ослепление, барьер, лишний урон по смерти и тьме. Тип урона: свет.
- **Сила** - мышцы героя: бросок, крик, толчок телом, оглушение ударом. Тип урона: физический. Не клинок из тени и не стрела.
- **Скрытность** - клинок из слепой зоны, кровотечение, удар по уже помеченной цели, короткая невидимость. Тип урона: физический. Не магия тьмы.
- **Стрельба/Охота** - выстрел, метка, капкан на клетке, дальний физический урон. Тип урона: физический. Не клинок и не зверь.
- **Тьма** - мрак на клетках, слабость, вампиризм тенью, зона где враги бьют реже. Тип урона: тьма. Не скрытность.

## Враги

Кластер без аспекта. Способность врага бьёт героя, самого кастера или других врагов. Стихию аспекта ей не приписывай: это отдельный набор (укус, рык, щит союзника, удар копьём). В поле аспекта пиши `враги`.

Типы применения врага:

- `герой` - удар или дебафф по герою, сетки нет
- `себя` - бафф, щит, лечение кастера
- `союзник` - один другой враг
- `союзники` - все остальные враги
- `зона` - узор на сетке 4×4, задевает врагов на этих клетках

Герой стоит под сеткой, не на клетке. Зона врага не целится в героя.
