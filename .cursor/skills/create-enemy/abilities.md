# Способности врагов (из create-enemy)

Карточки кластера `враги` лежат в `src/abilities/abilityDefs/enemies/`. Форма дефа, типы применения врага, сетка и шкала чисел - как в скилле `create-ability`: его [format.md](../create-ability/format.md) и раздел "Враги" в [aspects.md](../create-ability/aspects.md). DoT и эффекты - [EFFECTS_AND_DOTS.md](../../../design/meta/EFFECTS_AND_DOTS.md) (враги используют те же слоты/флаги, где применимо). Язык **numbers** и баффов/дебаффов - тот же, что у героя: скорость/урон "% снижена / повышена", не `интервал ×…` (см. format.md, раздел "Язык чисел для игрока").

Этот файл - только правила **когда create-enemy сам заводит способность**.

## Когда создавать

Создавай карточку способности, если пользователь:

- просит способность / N способностей для юнита или пачки;
- описывает приём ("тяжёлый удар булавой с оглушением");
- явно хочет мини-босса / элиту с приёмом.

Не создавай по умолчанию для обычной пачки без запроса. Большинству рядовых хватает автоатаки.

## Что взять от пользователя

1. Есть **имя и/или описание** - следуй им. Додумай только числа, кулдаун и тип применения, если их нет.
2. Есть только "1 способность" / "со способностью" без сути - **придумай** приём под роль, оружие и крючок юнита.
3. Пользователь ссылается на **уже существующий** id (`dark_arrow`) - новую карточку не плоди, впиши id в поле `abilities` врага.

## Дубли и похожесть

У кластера `враги` **можно** повторять скелет и решение. Много юнитов в мире - одинаковый "рык" или "тяжёлый удар" у разных групп нормален.

- Новый id и русское имя, если это отдельная карточка (даже при похожем эффекте).
- Или переиспользуй существующий id, если пользователь хочет общий приём.
- Не отказывай из-за "уже есть похожая Стрела тьмы".

Имена в каталоге всё же не сталкивай: одно и то же русское название под двумя id не заводи без просьбы.

## Запись способности

1. `aspectId`: `"enemies"`.
2. Файл: `src/abilities/abilityDefs/enemies/{id}.ts`. `id` - snake_case, уникальный в каталоге способностей.
3. Иконка-заглушка: скопируй `assets/art/skills/no_image.png` → `assets/art/skills/{id}.png`. Готовый файл не затирай. В деф: `icon: "{id}.png"`.
4. Мана у врагов обычно `manaCost: null`, если пользователь не просит иное.
5. Статус новой карточки - `"черновик"`. Блок `combat` не добавляй (пока нет реализации в бою).
6. Строка в `design/abilities/INDEX.md` (тот же формат, что у create-ability).
7. В дефе врага поле `abilities`: массив боевых id snake_case (`["crushing_blow"]` или `["dark_arrow", "war_cry"]`).

В код боя (`Battle.ts`, `AbilityId`) этим скиллом не пиши.

## Ориентир под роль юнита

| Роль юнита | Типичный тип применения | Идеи приёма |
|---|---|---|
| ближник / танк | герой / себя / союзники | тяжёлый удар, щит, крик на союзников |
| дальник / лучник | герой | залп, яд на стреле, подготовка выстрела |
| маг / ритуал | герой / зона / союзник | подготовка каста, порча, бафф союзнику |
| мини-босс | герой (часто сильнее полосы) | удар с контролем, фаза, аура на союзников |

Числа - из шкалы create-ability. Для удара по герою смотри HP героя (~300 на старте): лёгкий приём ~24-40, обычный ~36-55, тяжёлый / босс ~55-80 за попадание (или подготовка + удар, как у "Стрелы тьмы").

## Ответ в чате

Если в том же запросе созданы способности - добавь вторую маленькую таблицу: название способности, тип, крючок, файл, кому выдана. В ответе укажи английский id и имя файла иконки.
