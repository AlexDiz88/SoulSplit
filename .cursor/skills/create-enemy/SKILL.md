# Create Enemy - Soul Split

Генератор карточек врагов для бестиария. В код боя (`src/combat/enemies.ts`) ничего не пишет: игрок потом сам отбирает черновики.

## Вызов

Примеры:

- `/create-enemy Руины`
- `/create-enemy Бандиты, 5`
- `/create-enemy Служители алого ордена, 3, все в алых одеждах и с ритуальным оружием`
- `create-enemy Северная дорога, 4`

Разбор:

1. Убери ведущий `/create-enemy` или `create-enemy`.
2. Разрежь остаток по запятым.
3. Параметр 1 - **тема**: регион или группа (обязательно).
4. Среди остальных параметров: целое число = сколько врагов сгенерировать; всё остальное = обязательные особенности.
5. Числа нет - **3**.

Тема пустая или двусмысленная - один вопрос, без генерации.

## Перед дизайном

1. Прочитай [regions.md](regions.md) и [format.md](format.md).
2. Прочитай [INDEX.md](../../../design/enemies/INDEX.md).
3. Прочитай **целиком** карточки целевой группы (`design/enemies/{group_id}/`), если папка есть.
4. По INDEX просмотри крючки других групп. Если крючок похож на задумку - открой ту карточку.
5. Регион / группу не подменяй молча. Нет в каноне - либо спроси один раз, либо заведи новую группу с честным `group_id`.

## Что считать копией

Одинаковый скелет разрешён. Запрещена копия решения.

- **Скелет** - роль + reach (танк reach 1, лучник reach 3, маг reach 4).
- **Решение** - чем враг отличается сверх скелета: щит и медленный удар, копьё с reach 2, подготовка заклинания, яд на стрелах, крик на союзников.
- Копия - тот же скелет и то же решение, даже если имя и числа другие.
- Внутри одной группы нельзя повторять и скелет без нового решения.

## Уровень и статы

У каждого врага есть **базовый уровень** (поле бестиария). В бою движок сам бросает оффсет -2…+2 (кап 1-20) и масштабирует HP/атаку. В карточке пиши статы **на базовом уровне**, не на оффсете.

Полоса чисел - в [format.md](format.md). Ориентир региона - в [regions.md](regions.md). Не выходи из полосы без игровой причины, и эту причину формулируй как правило для игрока в **Описание** / **Доп**, а не как заметку о балансной таблице.

## Текст для игрока

Описание - как в бестиарии классической RPG: одно-два предложения, кто это и как дерётся. Числа не повторяй.

Поле **Доп** только для правила, которое игрок должен знать и которое не вошло в описание. Если такого правила нет, **Доп** не добавляй. Не пиши заметки разработчика: прототип, "в коде этого нет".

## Запись

1. Составь список из N разных имён и решений **до** записи файлов. В одном списке не должно быть двух одинаковых скелетов. Имена не совпадают с уже существующими в INDEX.
2. Собери карточку по шаблону из [format.md](format.md).
3. Сохрани в `design/enemies/{group_id}/{id}.md`. `id` - латиница, kebab-case, уникальный в каталоге. `group_id` - kebab-case.
4. Портрет-заглушка. Английское имя файла - `id` через подчёркивания: `goblin-spear` → `goblin_spear.png`. Скопируй `assets/art/enemies/no_image.png` в `assets/art/enemies/{имя}.png`. Если файл уже есть - не затирай. В шапку карточки запиши `portrait: {имя}.png`.
5. В ответе пользователю всегда указывай английский id и имя файла портрета. При смене русского названия синхронно меняй id (см. `.cursor/rules/id-rename.mdc`).
6. Допиши строку в INDEX. Крючок обязан содержать reach/ряды и решение.
7. Статус новой карточки - `черновик`. Карточки со статусом `одобрено`, `отказ` или `под вопросом` не трогай.

Бестиарий в игре читает эти карточки и `portrait`. Формат не ломай. Боевой пул зон этим скиллом не обновляй.

Между карточками подтверждения не спрашивай.

## Ответ в чате

Не разворачивай пачку полных карточек. Таблица: название, группа, ур., крючок, файл. Полный текст только в файлах.

В конце коротко: сколько создано, тема, путь к INDEX.
