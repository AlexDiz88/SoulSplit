# Формат карточки врага и шкала

## Бой, к которому привязаны числа

Один герой снизу. Враги на сетке **4×4**. Ряд 1 - ближний к герою, ряд 4 - дальний.

Карточка хранит статы на **базовом уровне**. В бою уровень = `baseLevel + случайный оффсет -2…+2` (итог кап 1-20). Статы сами растут/падают от оффсета (~12% HP и ~10% атаки за уровень). В бестиарии показывай только базовый уровень и базовые статы.

Прототип героя ур.1: ~300 HP, оружие 20-30 / 1.5 с. Ориентиры пачек - `design/meta/BALANCE_V1.md`.

## Полосы по базовому уровню

| Баз. ур. | HP | Урон автоатаки | Кулдаун | Типичная роль |
|---|---|---|---|---|
| 1-2 | 50-90 | 6-10 | 1.6-2.4 с | лёгкий ближник / лучник |
| 3-5 | 70-150 | 9-14 | 1.8-2.8 с | танк / маг / охотник |
| 6-10 | 120-220 | 12-20 | 1.7-3.0 с | элитный рядовой региона |
| 11-15 | 180-320 | 16-28 | 1.6-3.2 с | тяжёлый юнит |
| 16-20 | 260-450 | 22-36 | 1.5-3.4 с | верхняя полка |

Танк ближнего ряда: HP у верхней границы полосы, урон средний, reach 1, spawnRows включают 1.

Дальний маг / лучник: HP у нижней границы, урон выше, reach 3-4, spawnRows 2-4.

Не клади всех в один ряд. В пачке группы нужны и ближники, и дальники.

## Поля боя

- **Дистанция (reach):** 1 ближний … 4 дальний. Как далеко бьёт автоатака.
- **Появление (spawnRows):** ряды 1-4, где враг может встать. Обычно пересекается с reach, но танк может стоять только в 1, а маг только в 3-4.
- **Оружие:** одно из `melee` | `spear` | `bow` | `staff` (как в коде).
- **Аспект:** один из аспектов героя (`might`, `stealth`, `fire` …) - для цвета/тематики, не для гримуара.
- **Способности:** id способностей кластера `враги` через запятую (`dark-arrow`, `crushing-blow`) или `нет`. Новые id заводи этим скиллом по запросу пользователя (см. [abilities.md](abilities.md)): карточка в `design/abilities/enemies/` + строка в `design/abilities/INDEX.md`. Без запроса способностей большинству черновиков достаточно автоатаки (`нет`).

## Код (short)

2-4 заглавные кириллические буквы для подписи без портрета: `ГБЛ`, `СКМ`. Уникален в каталоге.

## Шаблон файла

```markdown
---
id: goblin-spear
portrait: goblin_spear.png
name: "Гоблин-копейщик"
short: "ГБЛ"
group: "Гоблины"
group_id: goblins
region: "Северная дорога"
region_id: north_road
status: черновик
base_level: 1
---

# Гоблин-копейщик

- **Группа:** Гоблины
- **Регион:** Северная дорога
- **Описание:** В духе классических RPG: одно-два предложения, без сленга и без чисел (числа в полях ниже).
- **Базовый уровень:** 1
- **Здоровье:** 68
- **Урон:** 7
- **Кулдаун:** 1.7 с
- **Дистанция:** 2
- **Появление:** ряды 1-2
- **Оружие:** spear
- **Аспект:** might
- **Способности:** нет
```

Поле `portrait` - файл в `assets/art/enemies`. Новому врагу это копия `no_image.png` под английским именем: дефисы `id` меняются на подчёркивания (`goblin-spear` → `goblin_spear.png`). Готовый файл с тем же именем не затирай.

Если регион неизвестен или враг кочует между регионами - `region` / `region_id` можно оставить пустыми, группу всё равно укажи.

`status`: новая карточка `черновик`. Утверждённые - `одобрено`. Вручную игрок может поставить `одобрено`, `отказ` или `под вопросом`. Генератор эти статусы не меняет.

## Крючок для INDEX

Одна строка: reach/ряды + роль/решение для навигации. Пример: `reach 1, ряд 1, толстый мили-танк`. Похожие крючки у разных групп допустимы.
