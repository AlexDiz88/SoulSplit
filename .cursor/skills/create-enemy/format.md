# Формат дефа врага и шкала

## Бой, к которому привязаны числа

Один герой снизу. Враги на сетке **4×4**. Ряд 1 - ближний к герою, ряд 4 - дальний.

Деф хранит статы на **базовом уровне**. В бою уровень = `baseLevel + случайный оффсет -2…+2` (итог кап 1-20). Статы сами растут/падают от оффсета (~12% HP и ~10% атаки за уровень). В бестиарии показывай только базовый уровень и базовые статы.

Прототип героя ур.1: ~300 HP, оружие 20-30 / 1.5 с. Ориентиры пачек - `design/meta/BALANCE_V1.md`.

## Полосы по базовому уровню

| Баз. ур. | HP | Урон автоатаки | Кулдаун | Типичная роль |
|---|---|---|---|---|
| 1-2 | 50-90 | 6-10 | 1.6-2.4 с | лёгкий ближник / лучник |
| 3-5 | 70-150 | 9-14 | 1.8-2.8 с | танк / маг / охотник |
| 6-10 | 120-220 | 12-20 | 1.7-3.0 с | элитный рядовой региона |
| 11-15 | 180-320 | 16-28 | 1.6-3.2 с | тяжёлый юнит |
| 16-20 | 260-450 | 22-36 | 1.5-3.4 с | верхняя полка |

Танк ближнего ряда: HP у верхней границы полосы, урон средний, reach 1, spawnRows включают 1.

Дальний маг / лучник: HP у нижней границы, урон выше, reach 3-4, spawnRows 2-4.

Не клади всех в один ряд. В пачке группы нужны и ближники, и дальники.

## Поля боя

- **reach:** 1 ближний … 4 дальний. Как далеко бьёт автоатака.
- **spawnRows:** желаемые ряды 1-4 для формации (не жёсткий запрет). Обычно пересекается с reach: танк хочет 1, маг 3-4. При переполнении пачки юнит встаёт в ближайший свободный ряд; приоритет клетки: ниже reach, затем уже spawnRows.
- **weapon:** одно из `melee` | `spear` | `bow` | `staff` (как в коде).
- **aspect:** один из аспектов героя (`might`, `stealth`, `fire` …) - для цвета/тематики, не для гримуара.
- **abilities:** массив боевых id (`["dark_arrow"]`) или не указывай / `undefined` для автоатаки. Новые id заводи этим скиллом по запросу пользователя (см. [abilities.md](abilities.md)): деф в `src/abilities/abilityDefs/enemies/` + строка в `design/abilities/INDEX.md`. Без запроса способностей большинству черновиков способности не нужны.
- **boss** / **threatMult:** для мини-босса / босса обычно `boss: true`, `threatMult: 1.5`.

## Код (short)

2-4 заглавные кириллические буквы для подписи без портрета: `ГБЛ`, `СКМ`. Уникален в каталоге.

## Шаблон файла

Путь: `src/combat/enemyDefs/{groupId}/{id}.ts`. `id` и имя файла - **snake_case** (`goblin_spear.ts`).

```ts
import type { EnemyDef } from "../types";

const goblinSpear: EnemyDef = {
  id: "goblin_spear",
  name: "Гоблин-копейщик",
  short: "ГБЛ",
  group: "Гоблины",
  groupId: "goblins",
  region: "Северная дорога",
  regionId: "north_road",
  status: "черновик",
  portrait: "goblin_spear.png",
  baseLevel: 1,
  reach: 2,
  spawnRows: [1, 2],
  hp: 68,
  atk: 7,
  cd: 1.7,
  aspect: "might",
  weapon: "spear",
  description:
    "В духе классических RPG: одно-два предложения, без сленга и без чисел.",
  hook: "reach 2, ряды 1-2, лёгкий ближник с копьём",
};

export default goblinSpear;
```

С способностью:

```ts
  abilities: ["dark_arrow"],
```

С доп. правилом для игрока:

```ts
  extra: "Появляется только в ряду 4.",
```

Поле `portrait` - файл в `assets/art/enemies`. Новому врагу это копия `no_image.png` под английским именем: `goblin_spear.png`. Готовый файл с тем же именем не затирай. Расширение может быть `png` / `jpg` / `jpeg` / `webp`.

Если регион неизвестен или враг кочует между регионами - `region` / `regionId` можно оставить пустыми строками, группу всё равно укажи.

`status`: новый юнит `"черновик"`. Утверждённые - `"одобрено"`. Вручную: `"одобрено"`, `"отказ"` или `"под вопросом"`. Генератор эти статусы не меняет.

Тип `EnemyDef` - в `src/combat/enemyDefs/types.ts`. Реестр подхватывает файлы через `import.meta.glob("./*/*.ts")` - отдельный импорт в `enemies.ts` не нужен.

## Крючок для INDEX

Одна строка: reach/ряды + роль/решение для навигации. Пример: `reach 1, ряд 1, толстый мили-танк`. Похожие крючки у разных групп допустимы. То же значение пиши в поле `hook` дефа.
